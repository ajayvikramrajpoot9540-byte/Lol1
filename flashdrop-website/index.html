🚀 Step-by-Step: How to Publish Your FlashDrop Website on GitHub Pages

📁 Where is the Website Code Located?

All website files are cleanly organized inside the /flashdrop-website folder in your project explorer:

  • flashdrop-website/index.html — Complete responsive HTML structure
  • flashdrop-website/styles.css — Official FlashDrop Green (#16A34A) & Orange (#FF8A24) styles
  • flashdrop-website/app.js — Camera Photo Search, Lowest-Price-First ranking, and 30-Minute Delivery engine
  • flashdrop-website/assets/flashdrop-logo.png — Your official FlashDrop logo
  • flashdrop-website/GITHUB_PUBLISH_GUIDE.md — Printable step-by-step instructions

Option A: Easiest Method (Upload Directly on GitHub.com — No Terminal Needed)

Step 1: Download the Project from AI Studio

Click the Settings / Export icon in AI Studio and choose Download ZIP. Extract the ZIP on your computer and open the flashdrop-website folder.

Step 2: Create a New Repository on GitHub

1. Go to github.com/new and sign in.
2. Enter Repository Name: flashdrop-website.
3. Select Public and click Create repository.

Step 3: Upload the Contents of flashdrop-website

1. On your new GitHub repository page, click "uploading an existing file".
2. Drag and drop index.html, styles.css, app.js, GITHUB_PUBLISH_GUIDE.md, and the assets folder from inside flashdrop-website/ into the browser window.
3. Click the green Commit changes button.

Step 4: Turn On Free GitHub Pages Hosting

1. Inside your GitHub repository, click Settings (top tab) → Pages (left sidebar).
2. Under Build and deployment → Branch, change None to main and folder / (root), then click Save.
3. Wait 60 seconds and refresh — your live website link will appear at:
https://<your-github-username>.github.io/flashdrop-website/

Option B: Publish Using Git Terminal Commands (One-Click Copy)

Run these commands inside the flashdrop-website folder:

cd flashdrop-website git init git add . git commit -m "Publish official FlashDrop website" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/flashdrop-website.git git push -u origin main
