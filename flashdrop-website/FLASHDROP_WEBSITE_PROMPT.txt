1. BRAND VISION & OVERVIEW
--------------------------------------------------------------------------------

- Service: Quick-commerce delivery connecting Mahoba residents with trusted local

- Core Philosophy:

--------------------------------------------------------------------------------
2. DATA PRIVACY, SECURITY & API ENCRYPTION STANDARDS (CRITICAL)
--------------------------------------------------------------------------------
To protect merchant, customer, and administrative integrity, the public website
must adhere to strict security boundaries:

A. Zero Public Exposure of Administrative & Merchant Back-Office Controls:
- NO public admin portals, admin credentials, or backend database consoles.
- NO display of shopkeeper passwords, owner personal IDs, GST numbers, phone
  records, or merchant profit/analytics dashboards to website visitors.
- NO exposure of customer user lists, saved login credentials, or private order
  histories across different users.
- The website operates as a secure, customer-facing public storefront and order
  placement portal.

B. Secure & Encrypted API Key Handling:
- NEVER hardcode raw API keys (Firebase, Google Maps, Gemini AI, Payment Gateways,
  or cloud tokens) in plaintext in public HTML, CSS, or client JavaScript files.
- All sensitive API calls must utilize encrypted tokens, backend proxies, serverless
  functions (e.g. Cloud Functions / secure REST endpoints), or client-side keys
  restricted by HTTP Referrer, SHA-1 fingerprints, and App Check security.
- Secrets must be injected via secure environment variables (`.env`) during build
  time and never committed to public repositories.

5. PUBLIC-FACING FEATURE SPECIFICATION
--------------------------------------------------------------------------------

FEATURE 1: MULTI-MODAL SEARCH (Text, Voice Mic, Camera Photo)
- Text Search: Live responsive filtering across product names, categories, and tags.
- Microphone Voice Search (🎤):
  * Web Speech API integration (`SpeechRecognition` / `webkitSpeechRecognition`).
  * Displays an animated audio listening modal with instant shortcut chips for testing
    ("Milk", "Atta", "Biscuits", "Tomatoes", "Pedha", "Notebook").
- Camera Visual Photo Search (📷):
  * Click photo via camera or pick from gallery to detect products visually.
- LEAST RATE / LOWEST PRICE FIRST SORTING (MANDATORY):
  * Available (in-stock) products are strictly sorted so the CHEAPEST available option
    is placed at the very top (#1 position).
  * Prominently marked with the green badge: "★ Least Rate / Lowest Price First".
  * Displays an interactive search banner below the search bar showing the detected
    item, availability status, and a quick "+ Add Lowest" action.

FEATURE 2: SMART 30-MINUTE FORWARD DELIVERY CALCULATION (IST)
- Synchronized with Indian Standard Time (IST = UTC+5:30).
- Calculates exact arrival time: `Current Time + 30 Minutes`.
  * E.g., Order placed at 10:15 AM -> "Expected Delivery by 10:45 AM".
  * E.g., Order placed at 11:40 PM -> "Expected Delivery by 12:10 AM (Tomorrow)".
- Dynamic Hero Banner with live clock and delivery estimate updating every 15 seconds.

FEATURE 3: STORE OPERATING HOURS & ORDER DECISION LOGIC
- Standard Operating Hours: 10:00 AM – 10:00 PM IST across partner stores.
- Store Status Badges:
  * Open Hours (10:00 AM – 10:00 PM): Displays green "OPEN NOW" badge.
  * Outside Hours (10:01 PM – 9:59 AM): Displays red "CLOSED" badge and notices:
    "Delivers Tomorrow by 10:30 AM".
- Near-Closing Logic (Within 30 mins of closing, e.g. 9:30 PM – 10:00 PM):
  * Displays "CLOSING SOON" badge.
  * System handles orders transparently: either delivers same night if open or
    schedules for next working morning (+30 mins).
  * Weekly holiday schedules automatically roll forward to the next working day.

FEATURE 4: PUBLIC NAVIGATION & STOREFRONT PAGES
1. Home Storefront:
   - Hero banner with live delivery estimate.
   - Multi-modal search bar (Mic, Camera, Text).
   - Category filter pills (Grocery, Sweets & Dairy, Vegetables, Pharmacy,
     Books & Stationery, Fashion, Electronics, Printing Press).
   - Products grid with photos, prices, MRP discount tags (% OFF), pack units,
     and "+ Add" buttons.
   - Verified local store cards with delivery times, distance, and live open status.
2. Partner Shops Directory:
   - Clean public directory of verified Mahoba partner stores.
   - Filter by store: Clicking any store displays its catalog and products.
3. My Orders & Live Tracking:
   - Displays placed orders with unique Order ID and payment method.
   - 4-Step visual delivery timeline: Confirmed -> Packing -> On the Way -> Delivered.
4. Product Quick-View Modal:
   - Click any product to view high-resolution image, pack size, price, MRP discount,
     store name, description, and "+ Add to Cart" action.
5. Terms & Policies:
   - 30-minute delivery policy, lowest-price guarantee, cancellation and refund policy.
6. Contact & Help Desk:
   - Head office address at Alha Chowk, Mahoba (210427), support hotline, and message form.

FEATURE 5: CART & DOORSTEP CHECKOUT
- Cart drawer with line items, quantity adjustments (+ / - / delete), subtotal,
  delivery fee (₹20), and calculated 30-minute delivery arrival time.
- Delivery Address Picker for Mahoba localities:
  * Subhash Chowk, Alha Chowk, Gandhi Nagar, Civil Lines, Sadar Bazaar, Station Road.
- Payment Options: Cash on Delivery (COD) or Instant UPI QR Code.
- Order Confirmation screen generating unique Order ID and adding to "My Orders".

FEATURE 6: TECHNICAL & DEPLOYMENT STANDARDS
- Built with pure HTML5, modern CSS3 (Flexbox, CSS Grid, CSS Variables), and vanilla
  modern JavaScript (ES6+).
- Completely self-contained with no bulky external dependencies.
- Zero-build required — deploys directly to GitHub Pages, Cloudflare Pages, Netlify,
  or standard hosting by hosting `index.html`.
- Mobile-first, fully responsive across phones (360px), tablets (800px), and desktops.
